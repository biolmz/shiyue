它做什么

不是又一个稍后读。是把「读完就没了」的东西，变成能回查、能引用的资料。

链接一贴就存

公众号、arXiv、DOI、PDF 直链、普通网页。自动抽正文、去导航和广告，配图下载到本地，断网也能回看。

PDF 文字层高亮

不是盖一张图上去，是真读文本层。按页记归一化坐标，缩放、换宽度之后高亮不会跑位。

Zotero 式三栏

左边分类和标签，中间条目，右边详情。双击就进阅读器，摘要和全文一键切换。

划线、批注、笔记

四色高亮自己定义含义，选中就浮出色板。批注按段落或按页锚定，右侧一整页笔记本写整篇的想法。

导出进 Zotero

整库导出 BibTeX，拖进 Zotero 直接认。单篇导出 Markdown，题录、笔记、划线摘录、原文一次带走。

纯本地，无账号

没有注册、没有云同步、没有埋点。文库就是一个文件夹，拷走即备份，换机器接着读。

支持什么链接

粘贴整段分享文字也行，会自动把里面的链接抠出来。

类型效果

arXiv题录 + 摘要 + 自动下载 PDF

数据在哪

纯本地，不经过任何服务器。

平台路径
Windows%APPDATA%\shiyue\library\
macOS~/Library/Application Support/shiyue/library/
源码运行项目目录/data/
菜单「文件 → 打开数据目录」直接定位。整个文件夹拷走，就等于备份或换机器迁移。

说在前面的话

这些限制绕不过去，先讲清楚比装完再失望好。

公众号偶尔会被微信拦。风控会返回「环境异常」，过一会儿再试，或者用浏览器另存网页。
付费墙论文只能存题录和摘要。全文抓不到是版权限制，不是技术问题。要点可以写在右侧笔记里。
扫描版 PDF 没有文字层，划不了高亮——需要 OCR，目前没做。
两个平台的包都没有代码签名。Windows 会提示「未知发布者」， macOS 首次打开要右键 → 打开。自己用完全没问题，公开分发建议买证书。
